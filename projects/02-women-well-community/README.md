# Project 02 — Women Well Community (WWC)

**AI-Assisted Infographic Design | Community Health Communication | Visual Storytelling**

**Project Status:** Portfolio Edition
**Location:** Singapore
**Target Audience:** Women aged 25–55, including working women and women managing household or caregiving responsibilities.

## Project Overview

Women Well Community (WWC) is a proposed six-week community-based preventive health initiative exploring practical wellbeing habits, stress awareness, and peer support.

This portfolio case study presents two AI-assisted infographic design approaches: an illustrated community-friendly version and a professional proposal-style version.

The visuals have been generalised for public portfolio presentation. This is a proposal concept, not an implemented programme or an institutionally endorsed initiative.
